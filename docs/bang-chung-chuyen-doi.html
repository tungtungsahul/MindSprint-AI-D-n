MindSprint AI · ASP.NET Core MVC

Bằng chứng chuyển đổi sang MindSprint AI MVC

Đối chiếu chức năng và kết quả kiểm thử của bản ASP.NET Core MVC trên nhánh main. Bảng ghi thời điểm của các thử nghiệm trình duyệt từ đợt chuyển đổi. Cập nhật ngày 26/11/2026. PR #130

Tóm tắt

1.844/1.844ca kiểm thử đạt với SQL Server
59bảng trong mô hình EF Core, gồm 8 bảng Identity
30 và 14FR và NFR trong Wiki
2/2job test và Docker đạt trên CI của be7352f
Có test có test tự động trong tests/ Đã thử Chrome đã bấm thử trên trình duyệt Chưa kiểm cần kiểm thêm Không chuyển cố ý bỏ, có lý do

Kiến trúc: giữ chức năng và giao diện nhóm, dùng khung QuizEdu

Bản nhóm cũ

  • frontend/: HTML + JS chạy trong trình duyệt (script.js 218 KB), triển khai trên Vercel
  • backend/MindSprint.Api: API ASP.NET Core 8, đăng nhập JWT, PostgreSQL trên Render
  • Bản phụ backend/app (Python FastAPI) + standalone.html

Project mới

  • Một project ASP.NET Core MVC (.NET 10), SQL Server, EF Core
  • Thứ tự lớp: Database → Service (quy tắc nghiệp vụ) → Controller → View (Razor) + JS nhỏ theo trang
  • ASP.NET Core Identity quản lý phiên thiết bị, xác thực hai bước, passkey, Google và Microsoft khi đã cấu hình.
  • Giao diện theo bản nhóm: màu xanh chanh, menu, bố cục, đối chiếu ảnh docs/giao-dien-nhom/01–18
